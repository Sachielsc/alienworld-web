# Goal

Tidy up the movies archive page. It is a long single column of stacked cards — YouTube
embeds first, then one card per Alien film with a `<dl>` of Plot / Year / Starring / etc.
Two things stand out:

- The page reads as an undifferentiated run of cards. There is no visual separation
  between the "video archive" section and the "movie collection" section below it, even
  though the two intro cards announce them.
- Inside each film card, the definition list is hard to scan — terms and values run
  together, and the Plot row is a bare unlinked URL sitting as body text.

Make the page easier to scan at all three widths, and check the video embeds keep their
aspect ratio on mobile.

# Constraints

- Keep the dark alien identity: the `#97ff77` green, Orbitron/Inconsolata, the existing
  `green-frame` / `white-frame` / `bg-planet-*` card treatments.
- Prefer `theme.css` custom properties and edits to existing classes over new one-off
  classes.
- No new dependencies, no CSS framework changes.
- The content lives in `client/src/content/movies.html` as a raw fragment — structural
  edits there are in scope, but keep every existing link, iframe and its `src`.

# Out of scope

- The site header and nav
- Which films are listed, and the copy of the intro cards
- The games page and anything under `/about/*` or `/workreport/*`

# Notes

This run is primarily a verification pass of the /frontend-beautify workflow itself
before the skill is extracted into a reusable plugin, so exercise the full path: the
`/movies` route deliberately has no dedicated view and must resolve through
`ContentPage.vue` + `content/movies.html`.
